بوت واتساب Rust — إصدار Linux x86 ‏(32-bit)

المتطلبات:
- Linux ‏32-bit أو Linux ‏64-bit يدعم تشغيل برامج i386.
- glibc ‏2.38 أو أحدث، مع مكتبات التشغيل 32-bit (i386).
- اتصال بالإنترنت.

التجهيز والتشغيل:
1. انسخ الملف .env.example إلى ملف باسم .env.
2. عدّل WHATSAPP_PHONE_NUMBER وضع رقمك بصيغة دولية من دون علامة +.
3. امنح الملف صلاحية التنفيذ عند الحاجة:
   chmod +x whatsapp-rust-bot
4. شغّله من هذا المجلد:
   ./whatsapp-rust-bot
5. اتبع تعليمات WhatsApp الظاهرة في الطرفية لإقران الجهاز.

تُنشأ جلسة WhatsApp في whatsapp_bot.db داخل مجلد التشغيل. احتفظ بهذا الملف ولا تشاركه.
لا يحتوي هذا الأرشيف على بيانات رقم هاتف أو جلسة خاصة.
